A programmer-focused portfolio theme featuring interactive terminal aesthetics, native Customizer controls, Google Fonts typography, and developer ligatures.

== Description ==

GeekyPress is a developer portfolio theme built for software engineers, full-stack developers, and open source contributors. It pairs a high-contrast terminal UI aesthetic with native WordPress Customizer controls and live preview editing.

Features:
* Out-of-the-box demo data showcasing projects, skills, career timeline, and contact information immediately upon activation.
* Native WordPress Customizer integration with repeater controls for projects, skills, timeline, and social links.
* Deep click-to-edit preview linking in the Customizer.
* Google Fonts integration with developer-centric monospace fonts (Fira Code, JetBrains Mono, Space Mono, and more) and programming ligatures support.
* Self-hosted local fallback fonts (Geist Sans & Geist Mono).
* Fully accessible, responsive mobile navigation drawer.
* Optional frontend terminal boot loader.

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance > Themes > Add New > Upload Theme.
2. Upload the `geekypress.zip` file and click Activate.
3. Upon activation, your front page will immediately display complete demo data.
4. Navigate to Appearance > Customize to edit your profile, biography, projects, skills, typography, and colors with real-time live preview.
